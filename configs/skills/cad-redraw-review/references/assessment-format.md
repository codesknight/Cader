# Cader assessment response

Use the following sections as a readable review, not as a machine-validated CAD spec.
Every conclusion must be tied to inputs actually inspected in this run.

1. Goal and scope: what the user wants, and what this read-only review can establish.
2. Inputs inspected: attachment references and tool results; distinguish unavailable files.
3. Evidence ledger: claim, value if readable, unit if established, source, uncertainty.
4. Open decisions: conflicts, missing measurements, occlusions, unsupported file inspection.
5. Proposed verification: dimensional constraints, structural checks, visual checks and saved-file checks, each with its required evidence and tool.
6. Next action: continue assessment, request specific information, or defer execution until required capabilities and authorization exist.

Keep unavailable checks explicitly unperformed. Do not output pass for an unexecuted
redraw or imply that a generated plan is an editable DWG. If evidence cannot establish
physical accuracy, say so even when the reference looks clear.
