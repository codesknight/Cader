# 电气示意图质量知识

这是按任务领域选择的知识数据，不授予任何工具权限。实际操作、审批与任务完成状态由执行层控制。

- 先区分电路原理图和物理接线布局。按原始需求选择元件与连接关系，不凭空补充电压、电阻、单位或元件。
- 电池式直流电源用平行、长短不等的两条极板表示。极板在电流路径方向上分离；两条外部引线分别终止于各自极板。两极板之间的间隙必须保留，不能画贯通间隙的导线，否则画成短路。旋转符号时，极板和引线一起旋转。
- 另一种直流电源画法是圆形电源符号并清楚标出正负极；圆内单独的十字也可能表示其他元件，应避免歧义。电压文字须靠近对应电源且不压线。
- 圆内交叉的 X 是常见灯泡符号，不应仅因为不是螺旋灯丝就判错。引线接在圆周的相对位置；X 和圆是符号本体，不是额外支路。
- 组件包围盒与端口采用绝对 CAD 坐标，不是每个组件重复使用的局部坐标。不同组件内部不能重叠；端口位于盒边界，盒可包含符号引线。
- 导线图层只表示组件外部连线。符号、内部引线和文字使用独立图层。外部导线止于端口，不能贯穿盒内部，也不能绕过元件把其两端短接。
- 仅明确的简单串联任务使用series_cycle：把每个两端元件视为一条边后，要求单一无支路闭环。分支、多端器件与手稿电路使用netlist，不能用series_cycle代替。
- netlist声明每个组件全部边界ports及同序pin_names，每个pin恰好属于一个外部导线net。晶体管等器件的各引脚不是内部短路，保留基极/集电极/发射极各自连接。单独悬空引脚显式列为单pin net。
- 原图重绘保留source_id及source_terminals（ports同序的原图零基端子索引），nets保持观察所得端子分组。布局坐标可调整，不能丢失第三端或改变公共回路。观察不确定时不得编造连接。
- 外部导线采用AcDbLine。T接点在端点处相连；纯内部交叉不自动相连，确有连接点的交叉必须在junctions显式声明并在非WIRE层实际绘制中心一致的小圆接点标记（半径不超过最短相交线长的15%）。仅声明坐标不证明CAD存在接点。避免重叠重复导线和无端点悬线。
- 立即逐组件调用实际工具，每个Patch最多8项；不要在单次响应预演整图。截断后只按Scheduler读回与确认账本补画未完成部分，不拼接残缺参数或重放已确认操作。
- 修改前查询实体 ID 和坐标。视觉检查侧重符号、标注和布局；几何/拓扑以实际查询为依据。图像不能分辨的微小间隙标为不确定，不猜测像素对应哪个实体。
- 局部修正应保留正确组件与连接。不要仅为满足图片模型的措辞而重画整图，也不能把电源极板间隙“修复”为导线。

- 符号实际引线必须到达每个声明端口；多段线只凭bbox不能证明端点，需要直线引线读回证据。已证实同坐标的相邻符号端口可直接接触，不能要求零长度WIRE。
- 原图局部uncertain不是确定断开；沿实际笔迹核对T接点与连续路径，不因手绘粗细/抖动而自行拆网。保留程序原图复核疑问及专门source_topology_fidelity最终条件；明确冲突不猜测，不改变已封存连接去迎合视觉建议。
