# Verification and repair
Before writes: target identity, units/scale status, permissions, frozen state, operation schema, region ownership and dependencies.
After each meaningful batch: independently query geometry and entity properties, capture relevant CAD view, compare against source crop or user specifications. Verify expected entities, location, orientation, labels and local connectivity where applicable. Use domain skills for symbols or standards; do not invent missing facts. Do not use visual similarity alone as proof of topology or dimensions.

Record discrepancy type, evidence reference, affected entities, expected vs observed, and next action. Repair only affected geometry, then re-query and re-render. Recheck neighbors if shared anchors changed. If no visual capture capability is available, report visual verification unavailable and do not mark it passed.

Final: check coverage of requested scope, overlap deduplication, cross-region connections, layout, annotations and applicable units; save and independently reopen if supported. Acceptance remains pending if any required check is absent. Preserve drafts explicitly as drafts.


In Cader, Harness already checks every effective batch. Read its current task evidence before requesting another review. During construction `cader_review_cad_view` reviews/reuses the current batch scope; it does not certify a whole region. Only submit `cader_finish_drawing_unit` or `unit_complete:true` when the region's required content is actually ready. Regional and final acceptance remain mandatory. Missing future content is not a defect of a partial batch, and plot zoom is not evidence against verified CAD coordinates. A bounded independent scope reconciliation may reuse the SAME image; both original and new reports remain evidence, and neither authorizes edits.

## Bound local evidence
Follow the current review_scope, not the apparent extent of the screenshot. Echo its scope_id and check each declared entity ID. A batch/subset defect must identify a submitted entity; unbuilt or background objects do not become batch requirements. Source trace IDs and native readback identify already verified line endpoints and literal text; pixel zoom cannot invalidate those coordinates. Complete-region and final coverage remain separate mandatory checks.

Harness requests actual native WCS-window plots and, where small text needs it, paired source/native closeups. They carry requested windows, pixel sizes and restoration evidence. Do not request a new full screenshot simply to obtain a higher magnification, add decoration to satisfy an imagined source, or interpret a crop edge as a wire endpoint. If strokes remain unobservable in the supplied detail, mark the corresponding target uncertain and explain what is unobservable; do not assume the DWG text is wrong solely from a tiny extents image. Unknown native capture results still require reconciliation before any retry.

A geometry_only draft proves only its admitted paths/circles/literal labels and their visibility/readability. Its trace schema has not captured stroke weight, fill, color or font: keep these explicit pending_source_attributes for later full-source acceptance, rather than asking MainAgent to invent a thick corner or filled symbol outside its contract. Use only the scoped primitive defect categories; this is NOT a full visual-fidelity pass. Small primitives, as well as text, may receive actual native closeups.


For geometry_only reviews, submit geometry_checks for every target's primitive_visibility (or expected_absence), plus text_readability for text. Each entry needs actual pixel evidence and pass/fail/uncertain. Scope verdict/checklist must match those target checks. Pending_source_attributes describes later whole-source obligations; it is not an invisible target and must not turn an already visible current primitive into uncertain. Truly unresolved target visibility/readability stays uncertain. Request retry is handled by DSH at the same open step; never repeat a confirmed CAD tool to compensate for a provider error. Exhausted provider failure returns to Scheduler and preserves the task; it is not evidence that the source was unreadable.

For indexed large line art, the construction checkpoint is primitive-only: observe every submitted entity, and verify native TEXT readability, without claiming complete labels, style or topology from an incomplete neighborhood. `partial_verified` never completes the task. Once all source IDs have confirmed native and primitive evidence, Harness must compare every exact paired high-resolution source/CAD window for all visible content, including decimal points, annotation groups and crossing geometry; then global coverage/connectivity/rendering and artifact checks remain mandatory. Do not replay confirmed prefixes, lower required conditions or treat source-only residual proposals as a CAD result. Report an actual missing target as a defect; retain uncertainty when supplied pixels cannot resolve a necessary condition.
