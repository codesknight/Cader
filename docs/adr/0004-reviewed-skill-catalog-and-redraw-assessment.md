# ADR 0004：重绘评估与显式 Skill 目录

- 日期：2026-11-19
- 状态：Accepted，先完成调研再实施
- 依据：[固定版本调研](../research/redraw-skill-integration-2026-11-19.md)

采用分层接入：Cader 独立编写重绘评估指引；将 Skill 配置和引用资源显式注册在
configs/skills/catalog.yaml，由 CLI 发现与 DSH Available / 按需工具共用。
资源只能按已注册 ID 读取，验证角色、文件范围和大小，不将文档或文件夹视为执行授权。
新增目录不自动注册，不执行脚本，不添加通用 shell、COM 或写 MCP 工具。

选择此方案的原因：上游工作流有参考价值，但当前没有明确 LICENSE；直接 COM 操作与
Cader 的文档绑定和未知写入对账不兼容；完整移植也需要 CAD 写入和独立验证能力先就绪。
不复制或分发上游文件。来源链接和 commit 作为研究溯源，不代表授权或上游背书。

用户可在只读 exec 中附 PNG 参考图。Skill 提供证据判断及后续验收计划，
图像感知由已配置模型完成，几何正确性、真实尺寸、DWG 保存与完整重绘继续单独验收。
主 Agent 决策、最多五个子任务、深度一和密钥隔离不变。

后续确定性 verifier 归入 #4；受控 MCP 绘制保存归入 #3。许可明确前，不将上游实现混入
Cader 的 MIT 分发，也不以动态 Skill 加载器绕过代码审查。
