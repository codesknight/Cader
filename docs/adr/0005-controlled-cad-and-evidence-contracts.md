# ADR 0005：程序受控 CAD 调度与独立证据

- 日期：2026-11-19
- 状态：Cader侧实现，外部协议与真实CAD验收待确认
- 工作项：[CADER-013 / #15](https://github.com/codesknight/Cader/issues/15)

联合测试表明模型运行、工具调用和业务完成需要独立表达。Cader负责识别、计划和验收，
MCP提供可靠的文档身份、执行和文件接口。

保留DSH+Cordis与默认只读Agent，独立程序调度器通过已审查计划哈希、操作白名单、显式HTTP
授权、全局锁和固定输出约束执行。派发前持久化意图；未知结果冻结、只对账。文件操作独立于图元事务。
请求/响应与业务schema放configs/contracts，策略放configs/cad；外部缺失接口标注提案，不回退活动文档。

复用Sharp/DSH附件服务实现原图区域与哈希/坐标链，事实及端口连通图由独立期望校验，
几何/文件/重开由程序查询验收。生成模型和Skill不能自行宣布通过或授予写权限。

本轮范围为三种固定几何操作、同机文件及同步成功响应；图片执行阻塞，没有自动恢复/解锁、
图像到CAD编译器或DWG电路拓扑提取。#3/#14在真实工作图与图片回归通过后逐步扩大范围。
