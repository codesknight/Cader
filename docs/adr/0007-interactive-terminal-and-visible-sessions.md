# ADR0007：Cader持续终端与可见会话

- 日期：2026-11-19
- 状态：已实施，Cader自有终端跨平台CI通过；真实模型多轮待配额恢复验收
- 关联：#16、#10、#9；用户明确要求可持续交互的Cader体验

原CLI只分发子命令，裸命令退出2使用户无法直接开始对话。以Node TTY/Readline提供彩色启动、持续输入、
共享Slash服务和快捷键，非TTY无参数帮助退出0；保留非交互exec JSON契约。安装本地bin/CMD入口，不放宽PowerShell策略。

社区候选已固定版本静态审查，依赖与必需服务不能直接套用当前装配；未运行社区profile，不关闭#9。
本轮不增加另一套Agent框架，保留DSH/Cordis、适配边界、五子Agent/深度1及默认只读。
会话恢复保存可见对话、引用身份、摘要和选择；每轮通过现有DSH服务装配这些数据，不恢复中间工具轨迹。
压缩关闭全部工具，Shell仅来自用户直接输入，需单独批准，输出不自动入模型上下文。

16个Slash命令均注册，但CAD执行按真实能力：任意DWG打开、undo、CAD快照恢复尚无接口；
明确返回能力缺口，不以菜单、摘要或会话checkpoint伪装CAD动作。用户期望与当前边界见[交互终端指南](../architecture/interactive-terminal.md)。
