# ADR 0014：手稿、任务、新图与 DWG 产物绑定

日期：2026-11-21；状态：实施；关联 REQ-034、BUG-029/030、[#20](https://github.com/codesknight/Cader/issues/20)。

审计证明用户粘贴的图片路径未成为模型像素输入，“复现”漏过质量路由，规划步骤没有原图，最后检查的是上一任务的 CAD 图。只增加提示词不能修复这些数据与执行绑定。

决定：

- 显式本地 PNG/JPEG 路径、`@` 或 `/open` 统一注册图片。外部选定图片复制为工作区哈希快照，只授权该图片，不扩大文件/Shell访问。路径选择与任务目标分别保留，后续“继续”恢复原始目标。
- 重绘描述符封存原始请求、原图哈希/像素尺寸、必须新建工作图及 DWG 目标。新增 `reference` 阶段复用现有 VisionAgent/DSH，读取受 schema 约束的结构观察；归一化图像坐标按真实宽高比转换为 y 向上的相对 CAD 坐标提示。观察不是 CAD 操作序列或工程尺寸。
- 原图显式传入规划、绘制和修正；验收必须同时比较原图与本任务 CAD 捕获。捕获文档、原图哈希及缺陷实体 ID 均检查。格式和错误实体引用有限次修复，不能靠报告文字宣称通过。
- 执行层拒绝在旧图上完成新任务，也拒绝同一重绘任务重建整图。验收前要求本任务新图确认、实际几何回执及当前查询中的本任务实体。冻结计划中明确禁止的导线穿组件在派发前检查，增量未闭合网络仍允许构建。
- DWG 由质量调度器经现有工具执行层保存，隐藏模型自由选择保存路径的入口。任务审批包含目标新文件，其他/外部已修改文件覆盖仍审批。保存回执、文件头、hash与保存后查询分别留证。未知写入不重放、不清锁。
- 几何、拓扑、源图外观和文件保存分别验收。未通过质量但可安全保存的结果明确为待验稿；全部必要条件通过且实际文件已核对才完成。原生 COM 没有权威 revision/只读重开证明，因此返回 `local_artifact`，不伪造 managed Artifact 身份。
- 同一连接恢复使用原任务 ID、计划、实体所有权与修正计数，不重复原始绘图。跨连接恢复不继承旧写权限。只有视觉重验的续轮不再因缺少主模型回答被误报失败。

保留 DSH/Cordis、Scheduler、独立 MCP 与现有恢复机制。没有新增 AgentLoop、固定电路操作序列或用模拟结果代替真实 CAD。真实验证与未完成项见[记录](../validation/2026-11-21-reference-redraw-fix.md)。
