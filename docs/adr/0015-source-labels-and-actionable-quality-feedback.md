# ADR 0015：源图标注绑定与可定位的质量反馈

日期：2026-11-21；状态：实施；REQ-035、[#20](https://github.com/codesknight/Cader/issues/20)。

服务恢复后完整测试显示：质量失败仍可能是缺陷反馈不可定位、标注字形误判、导线类型超出查询能力；更严重的是规划和视觉沿用同一错误源图读数，程序会对错误标注给出complete。不能只看模型的总评或降低门槛。

决定：

- 在现有源图观察后，对最多4个标注区域附带实际裁图重新读取。输入保留原图、区域索引及映射，不提供上次识别文字；报告用schema、索引集合和预算约束。仍是同一配置的视觉profile，不宣称不同模型间独立一致性，也不把fixture当真实OCR。
- 清晰源标注必须进入计划中的完整文字检查；数值及SI前缀不能被模型替换。局部复核仍不确定时可绘制并保存待验稿，程序禁止完成，不反复猜测单位。
- 标注按NFKC、排版空白和数学负号规范化后完整匹配，保留大小写，执行数量范围。不能把5V子串匹配到15V，也不能把m/M混同。原始字符串保留在查询证据。
- 串联图验证失败提供实际坐标、度数、导线ID、未连接端口/最近端点距离、组件边界候选及未支持实体。向修正步骤提供程序刚查回的实体，容差和验收计划保持，不由程序生成固定绘图序列。
- 当前MCP查询仅提供线段端点，串联任务的导线图层在派发前拒绝其他创建类型并给出线段替代；其他符号层仍可画多段线/圆弧。不把未支持类型忽略后宣称拓扑通过，也不扩大独立MCP改动。
- 视觉报告必须覆盖传入的视觉验收ID，各一次；不允许自行改名/遗漏/重复；非视觉条件不能混作视觉ID。沿用现有有界格式修复、原图hash/捕获文档/实体ID检查。
- 非重绘任务未请求文件保存时，规划不能凭空添加saved_dwg必选门槛。实际保存也不能代表后续修正已写回文件，最终状态需单列。
- 主模型使用现有low推理配置作实机对照，保留8192输出与原40步骤/100工具调用/3轮修正上限；视觉仍off。测试结果按实际组合记录，不把一次对照当统计性因果证明。可在模型YAML调整，DSH会话为内存，持久证据只记录可见结果与工具/验收数据。

不新增AgentLoop、固定电路计划或复杂评测平台。真正未知写入继续冻结，不重放、不迁移旧图权限。实机结果及剩余限制见[完整复验](../validation/2026-11-21-complete-quality-retest.md)。
