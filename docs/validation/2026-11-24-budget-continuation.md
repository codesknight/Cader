# 预算调度、检查点与自动续轮

日期：2026-11-24（Asia/Shanghai）。REQ-041，Cader #20 / Milestone 3，延续[dev.9预算审计](2026-11-23-tool-budget-audit.md)。用户明确要求修复预算调度，而不是仅扩大100或缩减正常需求。

## 实现

保留 DSH AgentLoop、Cordis、原 ExecutionSession、任务授权和 MCP 连接。Scheduler 在一次质量任务内启动新的 DSH 执行回合，不启动新 CAD 连接，不重新授权或接管旧图。

- `ExecutionBudget` 分别记录单轮/任务工具预留、单轮/任务 CAD 写请求、总模型步骤、服务商累计 token；任务600秒时限继续有效。默认值及语义见[中文手册](../cli/README.zh-CN.md)。token 是已报告用量的成本代理，不是精确货币限制；在途请求不能撤销计费。
- Patch 先验证全部原始 schema，再预留整批子操作；父入口也计工具额度。不足时任何子操作都不派发。实际故障仍停止在首个失败，不回滚或重放已确认前缀。
- 额度恰好耗尽时，pre-step 在下一次模型请求前交回 Scheduler；不要求模型再提交一个注定超限的操作才能续轮。工具额度给验证留出余量，Patch 的 schema 上限按单轮容量缩小，最多32项。
- 交接后 AgentLoop 已空闲。先持久化任务/计划hash/连接/图纸/操作与未派发队列，再查询全图并更新检查点。读回失败仍保留进度，禁止续写。原绑定复核通过后才启动下一回合。
- 下一回合通过 DSH 原工具服务先串行执行仅因预算拒绝、尚未派发的请求，原 schema、权限、文档检查与写审计仍生效；真实结果交给主模型继续决策。模型/任务总额度先检查，再允许队列派发。程序不重放部分失败的 Patch。
- unknown、冻结或连接/图纸改变阻止自动续写；已有屏障不解除。任务内第二次新建图也在执行层拒绝，避免续轮重建。
- 受控视觉入口在正常与异常路径均立即交回 Scheduler。报告已返回但后读回失败时，保留候选报告；下一次全图、连接、文档、写入和原图证据一致才可复用，避免重复截图。无效/取消/变化仍不能通过。
- 全图读回失败写入 `quality_snapshot_failed`，保留脱敏原始协议异常。CLI 显示检查点、自动续轮和任务总限额暂停；Available 包含预算、进度和真实续派结果。

自动续跑限定原进程中的同一任务。检查点持久化供核验，不表示重启后可恢复写授权；`/quality resume` 仍以安全重验为主，不自动绘制剩余部分。未实现跨进程任务迁移、精确货币计费预算或新的 AgentLoop。
